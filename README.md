GMG는 모임 생성자가 가능한 날짜, 시간, 장소 조건을 공유하면 참여자들이 가능한 시간을 입력하고 선호하지 않는 장소를 제외해 최종 모임 후보를 좁히는 서비스입니다.

# Main Features
- 모임 생성 플로우: 장소 유형, 날짜, 위치, 모임 정보를 입력해 공유 가능한 모임을 생성합니다.
- 참여 플로우: 참여자가 불가능한 시간과 선호하지 않는 장소를 등록합니다.
- 히트맵: 참여자별 가능 시간을 모아 날짜/시간대별 적합도를 표시합니다.
- 장소 추천: 참여자의 제외 조건과 이벤트 조건을 바탕으로 장소 후보를 조회합니다.
- 피드백 수집: 서비스 사용 중 피드백을 API로 수집합니다.
